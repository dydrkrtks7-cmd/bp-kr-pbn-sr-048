#### 현장에서 관찰한 작은 단서로 큰 차이를 설명
AWS Lightsail 인스턴스에서 CPU 크레딧 소진 3분 전 커널 패닉이 발생하는 특정 AMI 조합은 일반론적인 비용 절감 조언과는 전혀 다른 실 tế 속 이야기이다. 이 문제는 새벽 3시에 울린 페이저의 진짜 원인이 특정 리전 DNS 장애였던 썰을 중심으로 서사를 전개한다.

#### 현장 단서로 큰 차이를 설명
1. **온콜 엔지니어 시점**
AWS Lightsail에서 CPU 크레딧 소진 3분 전에 커널 패닉이 발생한 것은 AWS의 보안 세팅과 정기적인 리그닝 작업 때문일 것이다. 이 문제는 일반적으로 비용 절감 방법으로 제시되는 AWS EC2 또는 S3 서비스 설명과는 완전히 상관없다.

2. **새벽 3시에 울린 페이저의 진짜 원인**
